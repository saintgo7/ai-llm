## 사용 순서

**1) 실측값 수집 (회신 전 필수)**

```bash
ssh master
cd /path/to/ai-llm
./scripts/gpu_cluster_diag.sh master n1 n3
```

읽기 전용 점검만 수행하며 시스템 설정을 변경하지 않습니다. 소요 시간 약 5분.
결과는 `gpu_diag_<타임스탬프>/report.txt`에 저장됩니다.

DOCX/HWPX는 md에서 변환된 산출물입니다. md를 고쳤으면 재변환하십시오.

```bash

```

## 회신 시 핵심 논지

1. 저활용의 원인은 활용 의지 부족이 아니라 **24-GPU 멀티노드 클러스터링 미구성**이다.
2. 최우선 확인 대상은 **노드 간 인터커넥트(InfiniBand/RoCE) 가용 여부**이며, 자체 해결이 어려울 수 있어 기술지원이 필요하다.
3. `GPU Utilization` 단일 지표는 분산학습 환경의 활용도를 과소평가하므로 **자원 할당률 병행 반영**을 요청한다.
4. 클러스터링 해소 전에도 **독립 잡 병렬 투입(RL 롤아웃 등)** 으로 24-GPU를 즉시 가동할 수 있다.
