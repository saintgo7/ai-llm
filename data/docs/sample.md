# 샘플 문서: RAG 소개

RAG(Retrieval-Augmented Generation, 검색 증강 생성)는 언어 모델이 답변을 만들기 전에
외부 문서 저장소에서 관련 내용을 검색해 프롬프트에 함께 넣는 기법입니다.

## 동작 순서

1. 문서를 일정한 크기의 청크(chunk)로 나눕니다.
2. 청크를 검색 가능한 인덱스로 저장합니다.
3. 사용자 질문이 들어오면 관련도가 높은 청크를 찾습니다.
4. 찾은 청크를 컨텍스트로 붙여 모델에게 답변을 요청합니다.

## 장점

- 모델이 학습하지 않은 최신 정보나 사내 문서를 답변에 활용할 수 있습니다.
- 답변의 근거가 된 출처를 함께 보여줄 수 있어 검증이 쉽습니다.
- 모델을 다시 학습시키지 않고 문서만 바꿔서 지식을 갱신할 수 있습니다.
