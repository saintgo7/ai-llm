## Complexity Analysis

| Algorithm | Time Complexity | Space Complexity |
|-----------|----------------|------------------|
| BST Search | O(log n) avg, O(n) worst | O(1) |
| Merge Sort | O(n log n) | O(n) |
| Dijkstra | O((V+E) log V) | O(V) |
| Hash Table | O(1) avg | O(n) |
| Heap Operations | O(log n) | O(1) |
